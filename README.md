# online-retail-sales-dashboard
Online Retail Sales Analysis using Python, Pandas, and data visualization to identify sales trends, top products, and customer insights.

## 📌 Project Overview
This project analyzes online retail sales data to identify sales trends, top-selling products, and customer purchasing patterns.

## 🛠️ Tools Used
- Python
- Pandas
- Excel
- Google Colab
- Power BI 

## 📊 Key Features
- Monthly sales analysis
- Top-selling products
- Country-wise sales performance
- Top customers by sales
- Interactive dashboard

## 📁 Dataset
Online Retail transaction dataset from Kaggle.

## 🎯 Objective
To analyze sales data and generate useful business insights for better decision-making.

## 🔍 Key Findings
- Identified monthly sales trends and revenue patterns.
- Analyzed top-selling products by quantity.
- Identified top-performing countries by sales.
- Identified high-value customers based on purchase amounts.
- Generated business insights to support data-driven decision-making.
